Documentation · v6.0.0

Getting started

FORMA is one stylesheet and an optional script. No build step, no framework, no runtime dependencies. Tokens, themes and components are generated from a single source and every color pair is proven against WCAG at build time.

Install

Use the CDN, npm, or download dist/.

<!-- CDN (jsDelivr, pinned) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@nage/forma@6.0.0/dist/forma.min.css">
<script src="https://cdn.jsdelivr.net/npm/@nage/forma@6.0.0/dist/forma.min.js" defer></script>

# npm
npm i @nage/forma
import '@nage/forma/dist/forma.css';
import * as Forma from '@nage/forma';

The default Museum theme is self-hosted (Cormorant, Syne, JetBrains Mono — latin and latin-ext, so Turkish works). Keep dist/fonts/ next to the CSS.

Light, dark and themes

Mode follows the operating system by default. Force it on any element — the whole subtree follows, because every color token is a single light-dark() value.

<html data-mode="dark">            <!-- or "light"; omit to follow the OS -->
<html data-theme="cyberpunk">      <!-- after loading themes/cyberpunk.css -->
<section data-theme="editorial" data-mode="light">…</section>  <!-- scoped -->

Forma.mode.toggle();                 // persists the choice
Forma.theme.set('swiss');            // loads themes/swiss.css on demand

Tokens

Primitives live in tokens/primitives.tokens.json (W3C DTCG format). Colors are computed per theme from a handful of OKLCH parameters, then checked: text ≥ 4.5:1 (primary ≥ 12:1, secondary ≥ 6:1) on every surface, controls and focus rings ≥ 3:1. The build fails if any check fails.

Cascade layers

Everything sits in @layer forma.reset, forma.tokens, forma.base, forma.components, forma.sectors, forma.themes, forma.utilities. Your own unlayered CSS always wins — no specificity battles, no !important.

Browser support

Chrome/Edge 123+, Firefox 120+, Safari 17.5+ (2024 and newer). FORMA relies on light-dark(), color-mix(), @layer, :has(), container queries, <dialog> and the Popover API. Logical properties throughout, so dir="rtl" works.

Accessibility commitments

  • WCAG 2.2 AA contrast proven for every theme in both modes (1770 checks).
  • One :focus-visible rule components never override.
  • Native elements first: <dialog>, [popover], <details>, real checkboxes and radios.
  • WAI-ARIA patterns for tabs, menu, combobox, tree, grid date picker; full keyboard support.
  • Reduced motion respected; spinners keep moving slowly so state stays visible.
  • No user text is ever inserted as HTML by forma.js.
