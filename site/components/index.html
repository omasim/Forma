Components

126 components

101 in the core stylesheet, 25 in six optional sector modules. Every one is token-driven, keyboard-accessible and documented for humans and machines.

Core

Button

Actions. Eight intents, three sizes, icon-only, loading and grouped forms.

.btn

Badge

Compact, non-interactive status labels.

.badge

Tag & Chip

Tags are toggleable filters; chips are removable values.

.tag

Avatar

People and entities — round or square, six sizes, initials or image, grouped.

.avatar

Divider

Separation through restraint: three weights, vertical and labeled.

.divider

Icon

Stroke icons from the forma-icons.svg sprite (Lucide, ISC). Six sizes, semantic colors.

.fi

Spinner

Indeterminate loading indicator.

.spinner

Skeleton

Shape-preserving placeholders while content loads.

.skeleton

Progress

Determinate and indeterminate progress. Width comes from --value.

.progress

Status Dot

Tiny live-state indicators with text.

.status

Kbd

Keyboard keys and shortcuts.

.kbd

Tooltip

Short labels on hover and focus. Declarative via data-tooltip; rich variant for longer content.

.tooltip

Code & Log

Code blocks with a copy action, inline code, and terminal/log output.

.code-block

Forms

Field

Label, control, hint and message as one accessible unit. Validation state lives on the control via aria-invalid.

.field

Input

Text input, textarea and native select. Sizes, addons, icons, search.

.input

Checkbox & Radio

Native inputs, restyled. Indeterminate state, descriptions, and selectable cards.

.checkbox

Switch

Immediate on/off settings, as a native checkbox with role="switch".

.switch

Range

Native range slider with filled track; dual-thumb min/max via Forma.js.

.range

Segmented Control

A compact single choice between 2–5 options. Radio-backed for forms.

.segmented

Number Stepper

Numeric input with − / + buttons; respects min, max and step.

.stepper

OTP Input

One-time codes: auto-advance, backspace, paste-to-fill.

.otp

Combobox

Searchable single or multi select (WAI-ARIA combobox + listbox). Replaces v5 .cselect.

.combobox

File Upload

Drag-and-drop zone backed by a real file input, with a file list and per-file progress.

.dropzone

Date Picker

Calendar grid with keyboard navigation, single date or range. Rendered by Forma.js from a native date input.

.datepicker

Validation

Native constraint validation, enhanced: inline messages, an error summary, password strength. Messages in English and Turkish.

.form-summary

Surfaces

Card

The container. Five tones, header/body/footer parts, media, horizontal layout, interactive.

.card

Feature Card

Icon + title + description, for capabilities and product features.

.feature

Metric Card

A single number with label and trend. Display serif numerals, tabular figures.

.metric

Row Card

Horizontal list item for runs, files, people.

.row-card

Accordion

Native <details>/<summary> — keyboard and screen-reader support for free, animated height, no height cap.

.accordion

Alert

Prominent messages with title, text and actions. Also a full-width banner.

.alert

Callout

Quiet inline notes inside content and docs.

.callout

Empty & Error States

What to show when there is nothing yet, nothing found, or something broke.

.empty-state

Overlays

Dialog

Modal dialogs on native <dialog>: real focus trap, inert page, Escape, top layer, animated entry and exit.

.dialog

Drawer & Sheet

Side drawers and bottom sheets — the same native dialog, different entrance.

.drawer

Popover

Non-modal floating panels on the native Popover API — light-dismiss and Escape built in. Positioned to the trigger by Forma.js.

.popover

Menu

Action menus: popover + role="menu" with roving focus, type-ahead, checkable items and shortcuts.

.menu

Command Palette

⌘K / Ctrl+K launcher with fuzzy filtering, groups and keyboard navigation.

.command

Toast

Transient notifications in a polite live region. Pause on hover/focus, actions, auto-dismiss.

.toast

Navigation

Link

Inline text links with a quiet underline that strengthens on hover.

.link

Navbar

Top application bar: brand, primary links, actions. Sticky translucent variant.

.navbar

Sidebar

App navigation rail with sections, counts and a collapsed icon-only mode. Pairs with .app-shell.

.sidebar

Breadcrumb

Hierarchy trail as an ordered list.

.breadcrumb

Pagination

Page links with current, disabled and ellipsis states.

.pagination

Tabs

WAI-ARIA tabs in four looks: line, underline, pill, vertical. Arrow keys, Home/End, automatic activation.

.tabs

Steps

Progress through a multi-step flow, horizontal or vertical.

.steps

Wizard

Multi-step form: steps + panels + navigation. Validates each panel before advancing.

.wizard

Mega Menu

Wide, multi-column navigation panel on the Popover API.

.mega

Bottom Navigation

Mobile tab bar with safe-area padding and 44px targets.

.bottom-nav

Footer

Site footer with link columns and a legal row.

.footer

Data

Data Table

Semantic tables with toolbar, sortable headers (aria-sort), row selection, sticky header, striped/compact, and stack-on-narrow.

.table

Description List

Key–value pairs: inline, divided, or as a metadata grid.

.dl

KPI

Headline numbers with trend and optional sparkline, in a responsive grid.

.kpi

Stats Row

A ruled strip of totals.

.stats

Timeline

Events over time, vertical or horizontal, with tone markers.

.timeline

Activity Feed

Who did what, when — with unread markers and quoted context.

.feed

Kanban

Columns of cards with drag-and-drop and a keyboard alternative (Space to lift, arrows to move).

.kanban

Calendar

Month view with events and today marker.

.calendar

List

Plain and interactive lists of rows.

.list

Tree View

Hierarchies — files, schemas, taxonomies — with the WAI-ARIA tree pattern.

.tree

Charts

Chart Container

The frame every chart sits in: title, headline value, canvas, legend, table toggle, tooltip. Series colors --data-1…8 are CVD-validated and stay the same across themes.

.chart

Bar Chart

CSS-only vertical bars for small series (no JS), or Forma.chart type="bar" for grouped bars with axes.

.bars

Horizontal Bars

Ranked comparisons with labels and values — readable at any width.

.hbars

Donut

Part-to-whole for up to five parts, with center total and legend.

.donut

Gauge

A single value against a range (0–100 by default), with threshold coloring.

.gauge

Sparkline

Word-sized trend line for KPIs and tables.

.sparkline

Heatmap

Intensity over a grid (activity by day/week) with a single-hue sequential scale, levels 0–5.

.heatmap

Treemap

Proportional areas via flex weights (--w).

.treemap
