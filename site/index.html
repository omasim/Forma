01 · Start

Three lines to launch

No npm, no bundler. Link the stylesheet, optionally the script, optionally a theme.

<!-- Core -->
<link rel="stylesheet" href="forma.min.css">
<script src="forma.min.js" defer></script>
<!-- Optional: a theme -->
<link rel="stylesheet" href="themes/swiss.css">  <html data-theme="swiss">

03 · Proof

Accessibility you can audit

Contrast is computed, not hoped for

1770 checks across 59 themes × 2 modes. The build fails below AA.

Native first

<dialog>, popover, <details>, real inputs. Focus traps and Escape come from the browser.

RTL & i18n

Logical properties everywhere; validation messages in English and Turkish.

AI-native

llms.txt, a JSON spec, editor rules and an MCP server — all generated from the same source as the CSS.

Forma

A museum-grade, token-driven design system. Every color proven against WCAG at build time.
